# Fantasy Armor 1.3

- Added the Dawncrest armor set.
- Added a description tooltip for Moon Crystal.
- Expanded translations to 12 languages: English, Japanese, Ukrainian, Russian, Simplified Chinese, Turkish, Korean, Spanish, Brazilian Portuguese, German, French, and Polish.
- Expanded Forge, NeoForge, and Fabric support, including Minecraft 26.1.2, 26.2, and 26.3.
- Changed Minecraft 1.19.4 armor upgrades to shapeless crafting-table recipes: ingredients can be placed in any order.
- Reworked configuration handling and armor attribute updates.
 
Configuration handling has changed, review your settings after updating.
